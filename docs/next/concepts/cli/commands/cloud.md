# serverpod cloud

https://docs.serverpod.dev/next/concepts/cli/commands/cloud

`serverpod cloud` forwards everything after it to the Serverpod Cloud CLI (`scloud`), so you can manage Serverpod Cloud projects without installing `scloud` separately.

For the full set of Cloud commands and options, see the [Serverpod Cloud CLI reference](https://docs.serverpod.dev/cloud/reference/cli/introduction.md).
