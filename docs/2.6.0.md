# Installing Serverpod

https://docs.serverpod.dev/2.6.0

Serverpod is an open-source, scalable app server written in Dart for the Flutter community. Serverpod automatically generates your model and client-side code by analyzing your server. Calling a remote endpoint is as easy as making a local method call.

[Watch the video](https://www.youtube-nocookie.com/embed/F7WKovEFdnw)

## Command line tools

Serverpod is tested on Mac, Windows, and Linux. Before you can install Serverpod, you need to have **[Flutter](https://flutter.dev/docs/get-started/install)** installed.

Install Serverpod by running:

```bash
$ dart pub global activate serverpod_cli
```

Now test the installation by running:

```bash
$ serverpod
```

If everything is correctly configured, the help for the `serverpod` command is now displayed.

## VS Code Extension

The Serverpod VS Code extension makes it easy to work with your Serverpod projects. It provides real-time diagnostics and syntax highlighting for model files in your project.

![Serverpod extension](https://docs.serverpod.dev/img/syntax-highlighting.png)

Install the extension from the VS Code Marketplace: **[Serverpod extension](https://marketplace.visualstudio.com/items?itemName=serverpod.serverpod)**

## Serverpod Insights

**[Serverpod Insights](https://docs.serverpod.dev/tools/insights.md)** is a companion app bundled with Serverpod. It allows you to access your server's logs and health metrics. Insights is available for Mac and Windows, but we will be adding support for Linux in the future.

![Serverpod Insights](https://docs.serverpod.dev/img/serverpod-insights.webp)
